# ENR 259 Color Sorting Robot

This repository documents the autonomous color-sorting robot built for Monroe Community College's ENR 259 engineering course. The robot uses Teensy 4.0 firmware to detect, collect, and sort red, white, and blue golf balls.

The maintained source code and technical documentation are in the [Autonomous Color Sorting Robot repository](https://github.com/TylerM-Personal/Autonomous-Color-Sorting-Robot).
